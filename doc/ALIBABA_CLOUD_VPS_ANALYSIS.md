## 🚀 Setup Alibaba Cloud VPS

### 1. Buat Akun Alibaba Cloud

1. Daftar di: https://www.alibabacloud.com/
2. Verifikasi email dan phone
3. Top up balance (minimal $10 untuk testing)

### 2. Buat ECS Instance

1. Login ke **Alibaba Cloud Console**
2. Pilih **Elastic Compute Service (ECS)**
3. Klik **Create Instance**
4. Pilih:
   - **Region**: Singapore (`ap-southeast-1`) atau India (`ap-south-1`)
   - **Instance Type**: `ecs.t5-lc1m1.small` (1 vCPU, 1GB RAM)
   - **Image**: Ubuntu 22.04 LTS
   - **Storage**: 20GB SSD
   - **Network**: VPC (default)
   - **Bandwidth**: 1Mbps (pay-as-you-go)
5. **Security Group**: Buka port 22, 80, 443
6. **SSH Key**: Generate atau upload SSH key
7. Klik **Create**

### 3. Setup Server

```bash
# SSH ke server
ssh root@<your-ip>

# Update system
apt update && apt upgrade -y

# Install dependencies
apt install -y python3 python3-pip git curl

# Clone repository
git clone <your-repo>
cd trading-quant

# Install requirements
pip3 install -r requirements.txt

# Test Binance API
curl https://api.binance.com/api/v3/ping
# Harusnya: {} (tidak ada error HTTP 451)

# Cek IP location
curl https://ipinfo.io/json
# Harusnya: country: "SG" (Singapore) atau "IN" (India)
```

### 4. Setup Trading Bot

```bash
# Setup environment variables
nano .env
# Tambahkan: BINANCE_API_KEY, BINANCE_SECRET_KEY, dll

# Test bot
python3 main.py
```
